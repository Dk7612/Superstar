Install Superstar

Superstar is built and tested primarily for Google Chrome. Opera GX is also supported as a Chromium-based browser.

Google Chrome (recommended)

Download the Chrome package, unzip it, and load the extension in Developer mode:

Download for Chrome (.zip)
  1. Extract Superstar-Chrome.zip to a permanent folder. Do not delete or move that folder after installation.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and select the extracted browser-extension folder (the folder containing manifest.json).
  5. Open Superstar, sign in, and make sure your access code has the Extension permission enabled. Reload the Superstar tab after signing in.

Chrome update note: Developer-mode installations do not receive automatic updates from Superstar's GitHub update feed. Update by downloading the newest ZIP, replacing the extracted folder, and clicking Reload on chrome://extensions. Automatic Chrome updates require publishing through the Chrome Web Store; the ZIP is prepared for that submission, but Superstar is not yet listed there.

Opera GX (also supported)

Opera GX uses Chromium and supports the same extension code. Install the signed Opera-compatible package:

Download for Opera GX (.crx)
  1. Download Superstar.crx.
  2. Open opera://extensions in Opera GX.
  3. Turn on Developer mode.
  4. Drag the downloaded CRX onto the Extensions page and confirm if Opera allows it. If Opera blocks direct CRX installation, use Load unpacked with the extracted Chrome ZIP folder instead.
  5. Open Superstar, sign in, and make sure your access code has the Extension permission enabled. Reload the Superstar tab.

Opera updates: The signed CRX is published with Superstar's update feed. Opera controls when it checks for updates and may apply its own installation restrictions. An unpacked installation must be updated manually.
