Install in Opera GX

  1. Download Superstar.crx using the button above.
  2. Open opera://extensions in Opera GX.
  3. Turn on Developer mode.
  4. Drag the downloaded Superstar.crx file onto the Extensions page and confirm the installation if Opera allows it.
  5. Open Superstar, sign in with your access code, and make sure that access code has the Extension permission enabled.

Automatic updates: Install the signed CRX package from this page, not an unpacked folder. Superstar publishes signed updates through its update feed, but Opera controls when it checks for updates and may enforce its own installation restrictions. The first switch from an unpacked Developer Mode copy to the signed package is a one-time manual install.

If Opera refuses the downloaded CRX, it may require a store-distributed listing instead. The signed package is not yet an Opera Add-ons Store listing.
